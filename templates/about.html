Project Overview

AI Cyber Threat Detection System is a college major project that leverages artificial intelligence and machine learning to detect cybersecurity threats in real-time. The system provides two core detection modules:

  • Website Threat Detection

    Analyzes website URLs to identify potential phishing attempts, malicious content, and security risks using AI-powered algorithms.

  • EXE Malware Detection

    Performs static analysis on Windows executable files to detect malware, trojans, and other malicious code patterns using machine learning models.

Machine Learning Workflow

1

Data Collection

Gathering datasets of malicious and benign websites and executables for training.

2

Feature Extraction

Extracting relevant features from URLs (length, special characters, domain age) and EXE files (PE headers, sections, entropy).

3

Model Training

Training multiple ML models including Random Forest, XGBoost, and Neural Networks on labeled datasets.

4

Model Evaluation

Testing models on unseen data, optimizing hyperparameters, and selecting the best performing model.

5

Deployment

Deploying trained models as API endpoints integrated with the Flask application for real-time predictions.
